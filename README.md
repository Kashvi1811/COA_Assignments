# 🖥️ COA Assignments

This repository is a collection of my **Computer Organization & Architecture (COA) assignments**.
All solutions are written in a **straightforward and to-the-point format**, making them useful for both submission and quick revision.

---

## 📚 What’s Covered

The assignments in this repo focus on key COA areas such as:

* **Cache Memory**
  Basics, mapping techniques, and performance-related questions

* **Memory Hierarchy**
  Concepts like different memory levels and locality

* **I/O Organization**
  Programmed I/O, Interrupts, and DMA-based questions

* **Processor Concepts**
  Simple problems related to pipelining and performance

* **Disk & Storage**
  Structure of disks and access-related concepts
